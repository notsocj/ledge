Adds an optional F1 companion with a next-race countdown, local weekend schedule and latest published podium from Jolpica.

- Enable **F1 companion** under **Settings → In the island**. It starts off by default and stays independent of persona presets.
- A compact layout uses the existing island and jelly animations. Countdown ticks stay quiet; notifications briefly interrupt and then return to F1.
- Saved schedules and podiums remain available offline, with update status. Missing start times stay unconfirmed, and scheduled starts show “Results pending” until results arrive.

This is a schedule and post-race companion, not live timing.
