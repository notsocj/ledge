Privacy

Last updated October 26, 2026

Kestrel has no account, no analytics and no server of its own. What it shows you is read on your Mac and stays there. This page lists every exception.

What stays on your Mac

  • Clipboard history is kept in memory only and is gone when Kestrel quits. Items that password managers mark as secret are never saved.
  • Notes are a plain file in ~/Library/Application Support/Kestrel.
  • Files on the shelf are references to files you dropped there. Kestrel doesn't copy or upload them.
  • Calendar events are read through macOS's own calendar access to show your week and warn you before meetings.
  • Codex usage is read from the session files Codex already writes in ~/.codex/sessions.
  • Settings live in Kestrel's standard macOS preferences.

What goes over the network

Two features talk to the internet, and only while they're switched on.

  • Synced lyrics. When a song plays, Kestrel looks it up on LRCLIB by title, artist, album and length. Nothing else is sent. Switch off Now playing in Settings and the lookups stop.
  • Claude usage. To show your Claude limits, Kestrel asks Anthropic's API for your usage, signed in with the login Claude Code already saved in your Keychain. Kestrel only reads that login. It never refreshes, changes or sends it anywhere else. If Claude Code isn't installed, nothing is sent.

Kestrel doesn't check for updates or send crash reports today. If that changes, this page will say so first.

Permissions, and why

macOS asks you before Kestrel can use any of these. Each one is optional; the tools that need it simply stay off without it.

  • Accessibility, to snap windows with ⌃⌥ and the arrow keys and to show volume and brightness in the notch instead of the big square on screen.
  • Calendars, for your week on Home and the meeting countdown.
  • Bluetooth, to show the battery of your AirPods when they connect.
  • Screen Recording, for area screenshots with ⌃⌥S. Screenshots are saved to your Mac, copied, and put on the shelf.

Kestrel notices when your microphone or camera is in use by asking macOS whether the devices are running. It never records from them.

Claude Code and Codex alerts

Agent alerts are off until you connect them in Settings. Connecting adds one small command to ~/.claude/settings.json and ~/.codex/config.toml so the agents can tell Kestrel when they finish or need you. Kestrel asks before changing either file, saves a backup next to each one, and keeps any existing Codex notify command working by running it afterwards. Disconnect removes the command again.

Removing everything

Quit Kestrel, disconnect agent alerts first if you connected them, then delete the app and the ~/Library/Application Support/Kestrel folder.
